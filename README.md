## 📌 Projects

### 🔹 [SSPO – Sveriges Placeringar](https://www.sspo.se) (Ongoing Project)

📖 A digital decision-support platform that helps Swedish municipalities and care providers manage placement cases in a clearer, more structured way. SSPO brings together needs assessments, matching, dialogue, documentation, and decision-making in one shared workflow.

⚡ **Highlights:**

- Enables municipalities to create structured placement cases based on individual needs and requirements
- Helps providers receive relevant enquiries and respond with clear, comparable information
- Creates a more transparent process with better documentation and decision support
- Focuses on improving the conditions for each placement while keeping the final decision with the responsible caseworker
- Designed to reduce misunderstandings and unnecessary administrative work between organisations

### 🔹 [Cemio](https://github.com/CWGertoft/Clemio) (Ongoing Project)

📖 A B2B platform for trade businesses, with support for groundworks and construction projects, to create accurate cost estimates and professional quotations faster. Clemio is not a marketplace: every company retains ownership of its customers, price libraries, and calculations. AI assists with structure and review, but never sets prices or changes a calculation without explicit user approval.

⚡ **Tech Stack:** Next.js, TypeScript, Supabase, PostgreSQL, FastAPI, Python, Vercel

✨ **Highlights:**

- Built a multi-tenant platform with Supabase Auth and Row Level Security
- Developed customer management, reusable price libraries and cost estimation workflows
- Integrated Python-based AI services for project calculations and review suggestions
- Implemented professional quotation generation with PDF exports and precise monetary calculations
